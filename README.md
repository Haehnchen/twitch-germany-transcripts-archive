# Twitch Deutschland Transkript Archiv

Dieses Repository ist ein Mirror der Texte von [legends.army](https://legends.army/). Es enthält Transkripte deutschsprachiger Twitch-Videos samt automatisch generierten Titeln und Beschreibungen.

Die Transkripte enthalten Zeitmarken, Überschriften und Spielabschnitte. Pro Kanal und Jahr sind sie in einer 7z-Datei zusammengefasst.

Die README-Dateien verlinken die Jahre, Kanäle und Videos.

[Archiv im Browser öffnen](https://haehnchen.github.io/twitch-germany-transcripts-archive/)
